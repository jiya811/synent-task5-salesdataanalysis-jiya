# Superstore Sales Analysis

## Objective
Analyze business performance using sales data.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Monthly Revenue Trends
- Top Selling Products
- Profit Analysis
- Regional Analysis

## Key Insights
- Highest sales from West region
- Technology category most profitable
- Discounts affect profits negatively
